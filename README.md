1. Objectives:

1.To develop a web-based Weather Dashboard that displays current weather information.

2.To integrate a public Weather API with a web application.

3.To allow users to search weather information by city name.

4.To display important weather details such as temperature, humidity, wind speed, pressure, and weather condition.

5.To implement asynchronous programming using JavaScript async/await and fetch().

6.To provide error handling for invalid city names and empty inputs.

7.To create a responsive and user-friendly interface.

8.To use AI assistance for API integration, debugging, error analysis, Git commit messages, and documentation.

3. Features:

1.City Search

2.Users can enter a city name and search for its weather.

3.Current Temperature

4.Displays the current temperature in Celsius.

5.Weather Condition

6.Shows conditions such as clear sky, clouds, rain, etc.

7.Weather Icon

8.Displays an icon representing the current weather.

9.Humidity

10.Displays the humidity percentage.

11.Wind Speed

12.Displays the current wind speed.

13.Feels Like Temperature

14.Shows the temperature that the user actually feels.

15.Atmospheric Pressure

16.Displays the current pressure in hPa.

17.Error Handling

18.Shows an error message when the city is invalid or the input is empty.

19.Responsive Design

20.The dashboard can adapt to different screen sizes, including mobile devices.

21.Enter Key Support

22.Users can press Enter instead of clicking the Search button.
